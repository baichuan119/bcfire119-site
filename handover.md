# Baichuan Fire independent site handover

## Delivered
- Responsive static website with English-first navigation
- Language switcher for English, Russian, Portuguese and Hindi homepage labels
- Home, About, Products, Contact, FAQ and Privacy pages
- Product family pages for sprinklers, hydrants, valves and hose reels
- SEO metadata, canonical URLs, Organization / ItemList / FAQ schema
- `robots.txt`, `sitemap.xml` and `llms.txt`
- CSS responsive layout for desktop and mobile

## Before launch
1. Replace externally hosted image URLs with approved, optimized local assets where possible.
2. Add the final logo file and confirm brand usage.
3. Connect the inquiry form to a real business email, CRM or form endpoint. The current form is a front-end demo and does not send mail.
4. Add final contact details: business email, WhatsApp, phone and office address.
5. Replace the starter privacy text with the company's final legal policy.
6. Confirm model-level standards, certificates, approvals and claims before publishing.
7. Review translations with a native speaker for Russian, Portuguese and Hindi.
8. Test all product images, links and forms after deployment.

## Cloudflare Pages
- Create a Pages project from this folder or a GitHub repository.
- Deploy the static files without a build command.
- Add `bcfire119.com` as a custom domain in Cloudflare Pages.
- Ensure DNS is managed in the intended registrar / Cloudflare account.
- Verify HTTPS, apex domain, `www` behavior and redirects.

## SEO checklist
- Submit `https://bcfire119.com/sitemap.xml` in the search engine tools used by the business.
- Confirm title, description, canonical and structured data on every page.
- Add Organization logo and final company contact details to schema.
- Add product-level specs, documents, FAQs and internal links as content is finalized.
